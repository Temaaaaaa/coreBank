# CoreBank Lite

CoreBank Lite is an educational banking REST API intended to demonstrate clear,
production-style backend development suitable for a Junior Java developer portfolio.

The current version supports customers and opening/read-only access to their bank accounts.
Transfers, deposits, withdrawals, transaction history, and account status changes have not
been implemented yet.

## Technology stack

- Java 21
- Maven and Maven Wrapper
- Spring Boot 3.5
- Spring Web and Spring Data JPA
- PostgreSQL 17
- Flyway
- JUnit 5, Mockito, and Testcontainers
- Springdoc OpenAPI
- Docker Compose

## Requirements

- Java 21
- Docker Desktop

## Local PostgreSQL

The Compose configuration uses safe development defaults. To customize them, copy
`.env.example` to `.env`; the real `.env` file is ignored by Git.

```shell
docker compose up -d
docker compose ps
docker compose down
```

To remove PostgreSQL together with local database data:

```shell
docker compose down -v
```

## Run the application

Start PostgreSQL first, then configure the application connection and run Spring Boot.
Example for Windows PowerShell when PostgreSQL is exposed on port 15432:

```powershell
$env:DB_URL='jdbc:postgresql://localhost:15432/corebank'
$env:DB_USERNAME='corebank'
$env:DB_PASSWORD='corebank_dev'
.\mvnw.cmd spring-boot:run
```

The application uses `DB_URL`, `DB_USERNAME`, and `DB_PASSWORD`. If `DB_URL` is not
specified, its local default uses `POSTGRES_PORT`, or port 5432 when that variable is
also absent.

## Customer API

Create a customer:

```http
POST /api/v1/customers
Content-Type: application/json

{
  "firstName": "Artem",
  "lastName": "Ivanov",
  "email": "artem@example.com"
}
```

Successful response: `201 Created`, with a `Location` header.

```json
{
  "id": "c4f540b1-194d-4be7-bb96-64df4b06334c",
  "firstName": "Artem",
  "lastName": "Ivanov",
  "email": "artem@example.com",
  "createdAt": "2026-07-11T18:00:00Z",
  "updatedAt": "2026-07-11T18:00:00Z"
}
```

Retrieve a customer:

```http
GET /api/v1/customers/{customerId}
```

## Account API

Open an account for an existing customer:

```http
POST /api/v1/customers/{customerId}/accounts
Content-Type: application/json

{
  "currency": "RUB"
}
```

Successful response: `201 Created`, with `Location: /api/v1/accounts/{accountId}`.

```json
{
  "id": "22222222-2222-2222-2222-222222222222",
  "accountNumber": "12345678901234567890",
  "customerId": "11111111-1111-1111-1111-111111111111",
  "currency": "RUB",
  "balance": 0.00,
  "status": "ACTIVE",
  "createdAt": "2026-07-11T18:00:00Z",
  "updatedAt": "2026-07-11T18:00:00Z"
}
```

Retrieve one account or all accounts of a customer:

```http
GET /api/v1/accounts/{accountId}
GET /api/v1/customers/{customerId}/accounts
```

Account numbers are generated by the server as 20 digits. A new account always has
balance `0.00` and status `ACTIVE`. Supported currencies are `RUB`, `USD`, and `EUR`.
The customer account list is not paginated in this first version. Monetary operations
are not implemented yet.

## Tests

Windows:

```powershell
.\mvnw.cmd test
```

Unix-like systems:

```shell
./mvnw test
```

Integration tests start an isolated PostgreSQL Testcontainer and do not use the
Compose database.
